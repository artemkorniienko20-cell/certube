## 🚀 Основний функціонал

- **🏠 Головна сторінка (Home Feed)**:
  - Стрічка відеокарток із прев'ю, авторами, кількістю переглядів та датою публікації.
  - Інтерактивна панель тематичних фільтрів (Усі, Ігри, Музика, Новини, Технології тощо).
  - Пошук відео в реальному часі.

- **📱 Certube Shorts**:
  - Вертикальний повноекранний формат перегляду коротких роликів.
  - Зручне гортання коліщатком миші або кнопками навігації.
  - Кнопки реакцій: «Подобається», «Не подобається», коментарі та репости.
  - Увімкнення/вимкнення звуку.

- **▶️ Інтерактивний Відеоплеєр**:
  - Модальний плеєр перегляду відео з адаптивним відтворенням.
  - Система лайків/дизлайків, збереження до списку «Переглянути пізніше».
  - Кнопка підписки на канал автора.
  - Блок інтерактивних коментарів із можливістю додавання власного коментаря.
  - Рекомендації схожих відео на бічній панелі.

- **🎥 Творча Студія (Studio Modal)**:
  - Запис відео з вебкамери та захоплення екрана безпосередньо у браузері.
  - Завантаження готових відеофайлів.
  - Додавання назви, опису та вибір категорії перед публікацією.

- **💎 Certube Premium**:
  - Окреме вікно оформлення підписки без реклами.
  - Інтерактивні анімації святкового конфетті при оформленні.

- **📚 Підписки, Бібліотека та Профіль**:
  - Вкладка «Підписки»: перегляд нових релізів від каналів, на які ви підписані.
  - Вкладка «Бібліотека»: історія переглядів, вподобані відео, плейлисти.
  - Вкладка «Профіль»: налаштування каналу та персональні дані.

- **📱 Адаптивність (Mobile & Desktop)**:
  - Нижня панель навігації для мобільних пристроїв.
  - Бічний сайдбар для настільних моніторів.
  - Підтримка жестів та адаптивний дизайн.

## 🛠️ Стек технологій

- **Збірка та середовище**: [Vite](https://vitejs.dev/)
- **Мова**: Vanilla JavaScript (ES Modules, Store / Pub-Sub pattern)
- **Стилізація**: Чистий CSS3 (Flexbox, Grid, CSS Variables, Animations)
- **Анімації**: `canvas-confetti`

## 💻 Локальне встановлення та запуск

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/artemkorniienko20-cell/certube.git
   cd certube
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Запустіть локальний сервер розробки:
   ```bash
   npm run dev
   ```

4. Відкрийте у браузері: `http://localhost:3000/` або `http://localhost:3002/`.

### 📦 Збірка проєкту (Production Build)

```bash
npm run build
```
Зібраний статичний проєкт буде створено у директорії `dist/`.

Для попереднього перегляду готової збірки:
```bash
npm run preview
```
